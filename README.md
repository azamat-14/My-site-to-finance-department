
# 💼 FINANCE PRO

### Moliya bo‘limi boshqaruv tizimi

**FINANCE PRO** — bu korxona va tashkilotlarning moliyaviy faoliyatini boshqarish, daromad va xarajatlarni nazorat qilish hamda moliyaviy hisobotlarni shakllantirish uchun yaratilgan web-sayt.

---

## 🚀 Loyihaning imkoniyatlari

- 🏠 **Bosh sahifa** — moliyaviy ko‘rsatkichlarni ko‘rish.
- 💰 **Daromadlar** — yangi daromadlarni qo‘shish va boshqarish.
- 💸 **Xarajatlar** — xarajatlarni kiritish va nazorat qilish.
- 📊 **Byudjet** — rejalashtirilgan byudjetni hisoblash.
- 👨‍💼 **Ish haqi** — xodimlarning oylik maoshini hisoblash.
- 📈 **Hisobotlar** — moliyaviy hisobotlarni yuklab olish.

## ⚙️ Loyihani ishga tushirish

2. `index.html` faylini oching.
3. Faylni brauzer orqali ishga tushiring.
4. Saytdan foydalanishni boshlang.
